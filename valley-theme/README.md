# valley-theme

北歐童話山谷風格的桌面版主題，外加右側的 🏡 Yoda's Studio 與 ☕ Yoda's Daily。

## 主題
- 奶油白、粉藍、薄荷綠、淡粉、森林綠的柔和配色，深淺模式都有。
- 會動的山谷背景（雲、松樹、山丘，夜晚有星空）。
- 圓角對話泡泡。

## ☕ Yoda's Daily
上方 **📊 用量**：上下文用量、5 小時與 7 天額度、本次 session 花費估算、上下文明細。

下方 **🎙 想法整理**：在輸入框說出想法 → 整理成結構化提示詞 → 補充或糾正 → 「放進對話框」或「複製」。
底部可切換主對話的自動整理模式（自動 / 總是 / 關閉）。

## 指令
- `/tidyup auto | always | off | status | panel`
- `/usage-pane`：重新打開 ☕ Yoda's Daily
- `/command-center`：重新打開 🏡 Yoda's Studio
- 單條訊息跳過整理：開頭加 `!raw` 或 `原文:`
