# quota-band

A quiet usage line under the prompt, in the app's own style:

`5-hour · 94% left · Resets in 4h 49m   ·   Weekly · 63% left · Resets Fri 12:00 AM`

Updates after each reply and every minute for the countdown. A window at 90% used or more is left out, since the app shows its own warning then. `/quota` hides or shows it.
